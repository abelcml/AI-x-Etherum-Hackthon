## 一、项目是什么

一个构建在 HSK Chain 上的任务悬赏框架：用标签定义任务与报价，由执行器交付成果，验收后结算奖励。

GitHub 代码修复是一个适配场景；CSV 清洗证明执行与验收可以扩展到非 GitHub 业务。项目是 HSK 上的应用，不是新建区块链或 L2。

共同流程：

```text
任务定义与报价 → 发布并托管赏金 → 接单与执行 → 提交成果
→ 验收与人工确认 → 批准结算 → 工作者领取奖励
```

## 七、推荐 5 分钟 Demo

1. **30 秒：问题。** AI 能产出结果，但交付标准、验收与付款需要统一流程。
2. **1 分钟：任务定义。** 选择代码或 CSV 套餐，展示标签、报价、期限和验收规则。
3. **1 分半：真实 CSV。** 执行去重，展示成功结果；再注入删行或错误内容，展示验收拦截。
4. **1 分钟：结算。** 展示批准、可领取余额、单独提现。页面未接入时明确为模拟，随后切换 job 1 的真实交易和余额证据。
5. **1 分钟：复用与价值。** 代码使用 PR＋CI，CSV 使用文件＋哈希，其他业务可以换执行器和验收器，共用任务与结算流程。
